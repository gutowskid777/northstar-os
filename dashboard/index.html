Overview
One page, six tabs, plain JSON underneath.
This is a personal dashboard you run on your own machine. The whole interface is a single HTML file with no framework, no bundler, and no build step. Everything you see is read from plain JSON files, and everything you change is written straight back to them. Nothing leaves your computer.
The Tabs
What each view is for.
Home
Your daily brief. Queue Health (four chips computed from the queue), Today's Focus (your top starred task), inbox triage, news, events, starred Life items, and Edge notes. Everything except the two computed blocks comes from morning-brief.json.
Builds
Every project in four columns: Active / Queue / Paused / Done. Drag a card between columns, or click its code pill to cycle status. Click a card to jump to that project's todos. The Master Build Order list below is drag-to-reprioritize.
Todo
Opens on Focus — starred items only. Sub-tabs: Focus | All | one per project. Drag to reorder, ★ to star, ✓ to mark done, ✕ to archive. Type in the add row to create an item.
Life
A nested outline for everything that is not a build: sections, subsections, and items. Each section renders as a checklist, a numbered list, or bullets. Star an item and it shows up on Home.
Archive
Done and archived rows from both the queue and Life. Read-only history with a restore button. Nothing is ever hard-deleted.
How It Works
This page, plus the skills list below.
Data Layer
Five files in dashboard/data/, plus the queue.
Edit them by hand, generate them with a script, or let the dashboard write them for you. They are ordinary JSON — nothing is encoded, hashed, or migrated. The one exception is the queue: it lives in brain/queue.json, outside this folder, because it is the single source of truth the rest of the system reads. A second copy under dashboard/data/ would fork it, so there isn't one.
projects.json
An array of projects: id, code, name, status, stack, next_actions. Status is one of active / queue / paused / done.
brain/queue.json
Not in dashboard/data/ — this is THE queue for the whole system, reachable over HTTP only through /api/queue. Shape: { "_meta": {...}, "items": [...] }. Every row needs id, type, and status; type is task, idea, decision, reference, or bug. The Todo tab renders only tasks, but writes preserve every row, so ideas and decisions can never be dropped by a save.
life-data.json
A tree of sections, subsections, and items. Keep the three inbox subsections — LIFE-SUB-UI, LIFE-SUB-U, LIFE-SUB-I — if you want the pin button on Home's inbox rows to work; that is where pinned emails land.
morning-brief.json
Everything on Home that is not computed: inbox, news, edge, events. News and event categories are declared in the file itself, so you add a category by adding data — not by editing HTML.
build-order.json
A flat array of project ids. Drives the Master Build Order ranking on the Builds tab.
skills-index.json
The list rendered at the bottom of this page. Use it to document whatever automations you point at this dashboard.
Daily Workflow
How to actually use this.
Morning
☀️
Open Home
Queue Health tells you whether the backlog is under control. Today's Focus names the one thing to do first. Below that: inbox, news, events.
Focus
⭐
Star three things
The Todo tab opens on Focus, which shows starred rows only. Star what you are actually working on today; everything else stays queued and out of sight.
Cleanup
🗃️
Archive aggressively
✕ archives, it never deletes — the row moves to the Archive tab and can be restored. A long open list is just noise.

Server
Zero dependencies. Localhost only.
serve.py is pure Python standard library — no web framework, no pip install, no virtualenv. If you have Python 3, you can run it. It serves this page and exposes a small /api/* surface over dashboard/data/ and brain/queue.json. Writes are atomic and keep a .bak of the previous version, so a crash mid-save cannot truncate your queue.
python3 serve.py
Run it from the repository root. Defaults to http://127.0.0.1:8000; override with PORT=8123 python3 serve.py. Without it running, the page still loads but every change is lost on refresh.
Do not port-forward it
It binds 127.0.0.1 and has no authentication, on purpose — it is a single-user tool on your own machine. Anyone who can reach the port can read and overwrite all of your data. Do not expose it to your Wi-Fi, a tunnel, or a container port map.
Only dashboard/ is served
dashboard/ is the entire static root, so /brain/queue.json, /.env, and /.git/config all 404 — there is no static path out of it. Files outside it are reachable only where a named /api/* route deliberately opens one, and each of those validates what it writes.
