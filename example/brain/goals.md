## How to use this file

- **Ties break downward.** When two things look equally urgent, the one attached to a higher-ranked
  goal wins. If neither is attached to a top-3 goal, that's the answer: probably neither.
- **Re-ranks get surfaced, never silent.** If the brain thinks the order is wrong, it says so and
  I decide. It does not quietly reorder this file.
- **This is the rabbit-hole reference.** "Off a top-3 goal" means off THIS list.
- **Re-read at the weekly review.** A goal list that hasn't changed in three months is either very
  good or completely ignored, and it's worth knowing which.
